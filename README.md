# Projeto Android - Curso em Vídeo

Este repositório contém o projeto prático desenvolvido durante o Capítulo 17 do curso de HTML5 e CSS3 do **Curso em Vídeo**, ministrado pelo Professor Gustavo Guanabara.

O objetivo do projeto foi aplicar conceitos fundamentais de design web, focando em estruturação semântica, criação de uma identidade visual baseada em paleta de cores, uso de fontes personalizadas e responsividade.

## 📱 Sobre o Site

A página conta de forma informativa e estruturada a história do surgimento do mascote do sistema operacional Android (o Bugdroid), detalhando desde os primeiros rascunhos de Dan Morrill (os Dandroids) até a versão icônica final criada pela ilustradora Irina Blok. O site também apresenta curiosidades sobre as nomenclaturas adocicadas das versões do sistema.

## 🛠️ Tecnologias e Conceitos Aplicados

* **HTML5 Semântico:** Uso correto de tags estruturais para melhorar a acessibilidade e o SEO (como `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>` e `<footer>`).
* **CSS3 Avançado:** * Declaração e uso de variáveis no `:root` para centralizar a paleta de cores (tons de verde e creme).
  * Importação e configuração de fontes locais e externas utilizando `@font-face` (*Bebas Neue* e *Android*).
  * Customização de elementos de listas e links com seletores e pseudo-elementos (`:after`, `:hover`).
  * Ajustes de layout com sombras (`box-shadow`) e bordas arredondadas.
* **Responsividade:** Layout adaptável preparado para visualização em diferentes tamanhos de tela.

## 📂 Estrutura do Repositório

O projeto é composto pelos seguintes arquivos essenciais:

* **`index.html`** - Estrutura de marcação e todo o conteúdo textual do artigo.
* **`style.css`** - Arquivo centralizador de estilos, regras visuais e tipografia.
* **`android-site.txt`** - Arquivo auxiliar contendo o texto bruto utilizado na produção do conteúdo.

## 🚀 Como Executar

1. Faça o download ou clone este repositório para a sua máquina local.
2. Certifique-se de manter os arquivos de estilo, imagens e fontes nas respectivas pastas estruturadas.
3. Abra o arquivo `index.html` diretamente em qualquer navegador web (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.) para visualizar a página executando.
